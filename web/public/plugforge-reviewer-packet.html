Do this first

Covers MVP gates 1, 2, and 8.

  1. Open the web app and sign in with dev@ship.local / admin123.
  2. Go to Workspace Settings → Developer. Click Create app.
    Pass if: secret shown exactly once; you cannot view it again (only rotate/revoke). If red API error: preflight failed — redeploy API.
  3. Open SDK demo. Paste client_id, click Connect, approve consent. After redirect: Connected. and Documents / Issues lists load (or “Loaded empty lists.”). Try Create to add a document.
    Pass if: redirect completes; lists load without auth errors.
  4. Confirm data loaded after connect (proves the SDK token works against /api/v1).
    Pass if: Connected/Loaded status and rows appear (or empty lists, no error). CI proves .me() in e2e/oauth-auth-code.spec.ts.
