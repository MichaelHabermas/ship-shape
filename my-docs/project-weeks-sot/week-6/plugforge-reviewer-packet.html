Key Proofs & Enforcement

  • Fitness + parity: api/src/platform/api/v1/route-metadata.test.ts — unique ops, explicit scopes from registry, SDK metadata matches real @ship/sdk methods, list endpoints declare pagination.
  • OpenAPI generation: api/src/platform/api/v1/openapi.ts (zod-to-openapi) + served route. Unit test validates the document against the 3.1 schema.
  • Public boundary: Separate router at /api/v1. Lint rule (and import boundaries) prevent leakage from internal handlers. All platform concerns (bearer validation, scope require(), rate limit headers, audit, webhook publish via IEventBus) attach only here.
  • Webhook reliability: api/src/platform/webhooks/ — event-bus (domain layer only), signature (Stripe t= + v1= HMAC), retry schedule with jitter, delivery log, DLQ after N failures, replay endpoint that preserves Idempotency-Key.
  • SDK: sdk/ — resource clients, deviceLogin + authorizationCodeFlow helpers, pluggable ITokenStore, verifyWebhook(headers, rawBody, secret), async-iterator pagination, typed errors.
  • TTFE drill: scripts/drill.mjs + pnpm drill ttfe. Real fresh-install semantics via packing; runs against containerized test DB; asserts signed + verified delivery.
  • CLI reference: integrations/cli/ — must-ship commands exercised by the drill and by the spec's "five-line developer story".
  • Agent-as-citizen: FleetGraph runtime now consumes via @ship/sdk + delegated OAuth tokens (see api/src/fleetgraph/public-api-client.ts and agent-token-broker). Same scopes, same audit trail, no privileged backdoors.

Architecture Highlights (from required docs/architecture.md)

Public / Internal split
/api/v1/* is the only public contract. Internal routes stay at /api/*. Same domain services (document mutations, issue service, etc.) are called from both; the platform layer (OAuth app + scopes + rate + audit + bus publish) is attached exclusively at the public boundary.
Event Bus + Webhooks
Domain writes publish to IEventBus (never routes). In-process deliverer for tests (deterministic); queue impl is substitutable. Subscriptions are per (app, event_type). Signing includes timestamp to bound replays.
Scopes as data
ScopeRegistry (OCP) — scopes registered at module load. require('documents:write') middleware produces clear 403s naming the missing scope. No stringly-typed magic in handlers.
SDK design
Hand-authored surface for quality + DX. Fitness test asserts every public OAuth route with an SDK mapping actually exists on the client. Async iterators hide cursor pagination from consumers.

Repro for Reviewers (live demo script)

  1. Start the system: pnpm dev (ensures DB, runs migrations, finds ports).
  2. In a clean terminal (or let the drill do it): pnpm drill ttfe. Watch the stages and the verified webhook arrive.
  3. As admin (dev@ship.local / admin123): Workspace Settings → Developer tab → create an app with documents:read documents:write webhooks:manage. Copy the client_id and the one-time secret.
  4. Open /sdk-demo, paste client_id, Connect (PKCE flow), create a doc through the SDK.
  5. In the Developer tab, watch the delivery appear; hit Replay on a failed one if you want to demo the DLQ/replay path.
  6. Optional: point the CLI at the running server with --api-url and --client-id (or use the drill's fixture output).
