# Reviewer Guide

Start here if you are reviewing the ShipShape submission.

## Audit Baseline

- Report: `my-docs/AUDIT_REPORT.md`
- Source-of-truth brief: `my-docs/SOURCE-OF-TRUTH/GFA-Week-4-ShipShape.txt`
- Orientation notes: `my-docs/Codebase-Orientation-Checklist.md`

Look for: baseline measurements for all 7 categories, methodology, tools used, ranked findings, and raw data references.

## Improvements

- Report: `my-docs/IMPROVEMENT_REPORT.md`
- Checklist: `my-docs/SUBMISSION_CHECKLIST.md`

Look for: latest measurements, change from baseline, source requirement quote, concise change summary, and evidence links for each category.

## Required Write-Ups

- Discoveries: `my-docs/DISCOVERY.md`
- AI cost analysis: `my-docs/AI_COST_ANALYSIS.md`

Look for: 3 codebase discoveries with file references, plus AI spend/usage and reflection on AI effectiveness for understanding the codebase.

## Evidence

- Audit evidence: `my-docs/audit-evidence/`
- Improvement evidence: linked from `my-docs/IMPROVEMENT_REPORT.md`

Look for: benchmark output, bundle reports, query counts, `EXPLAIN ANALYZE`, test output, accessibility reports, screenshots, or recordings.

## Setup And Verification

- Setup guide: `README.md`
- Local notes and durable gotchas: `my-docs/MEMORY.md`

Look for: accurate setup steps, test commands, deployment URL if applicable, and final verification notes.
